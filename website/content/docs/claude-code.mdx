title: Claude Code plugin

The mddog plugin for [Claude Code](https://claude.com/claude-code) shows a Markdown file in a pane right inside a session.

You can open a file yourself, or ask Claude to show you one. The pane works in the terminal, the Claude Code desktop app, and the VS Code extension.

![A Markdown file in the mddog pane beside the Claude Code chat](/docs/claude-code.webp)

## Install

1. [Install mddog](/docs#install)
2. Run these commands to add the plugin to your marketplace and install it:

```sh
claude plugin marketplace add qu8n/mddog && claude plugin install mddog@mddog
```

## Update

1. Re-run the [install script](/docs#install)
2. Update the plugin:

   ```sh
   claude plugin marketplace update mddog && claude plugin update mddog@mddog
   ```

3. Start a new Claude Code session, or run `/reload-plugins`

## Usage

- Preview a file with `/mddog <file.md>` or `/mddog @<file.md>`
- Ask Claude to show you a file, for example "show me the plan in mddog"
- Scroll the pane with the mouse wheel or click the pane and use the arrow and page keys
- The pane reloads when the file changes, so you see Claude's edits as it makes them

If Claude opens the pane and you don't see it, the terminal is too narrow. Zoom out, or run `/mddog <file.md>` yourself.

## Limitations

### Images

Claude Code shows images only in terminals it knows, such as Ghostty, iTerm2, kitty, and WezTerm. In other terminals, run:

```sh
CLAUDE_CODE_FORCE_TERMINAL_IMAGES=1 claude
```

### Desktop apps (e.g. Claude Code, VS Code)

The pane can't click links or select text.

If `/mddog` is the first message of a new session, you will see the error `"/mddog isn't a command here"`, the app shows this note, but the command still runs. This is because the app checks the first message before the plugin has registered `/mddog`. Later calls don't show it.
