title: Limitations
description: Known problems in some terminals, and how to work around them.

## Copy with Cmd-c

`Cmd-c` works only when the terminal passes it to mddog instead of running its own copy. Ghostty and kitty do this by default.

- In WezTerm, set `enable_kitty_keyboard = true` and remove WezTerm's `Cmd-c` (`SUPER+c`) binding. Without that, `Cmd-c` copies WezTerm's own empty selection, so it empties the clipboard, even after `copy_on_select` copied a selection.
- iTerm2 keeps `Cmd-c` for itself. Set [`copy_on_select = true`](/docs/config#copy_on_select) in mddog's config instead.
- In Ghostty, if you select with `Shift` + drag, Ghostty makes the selection, so `Cmd-c` copies Ghostty's selection.

## Warp and zellij

mddog refuses to run in Warp and zellij, because their bugs garble scrolling ([Warp#16424](https://github.com/warpdotdev/Warp/issues/16424), [zellij#5573](https://github.com/zellij-org/zellij/issues/5573)). In a multiplexer that runs inside Warp, such as herdr, mddog can't tell and runs anyway. Warp's own environment variables don't help, because a herdr session keeps the ones from the terminal it first started in. There, scrolling doesn't move the page, and `G` draws it squashed.

## tmux

tmux can't show images yet, so mddog doesn't run in it ([tmux#5445](https://github.com/tmux/tmux/pull/5445)).

## herdr

In herdr, images reach every terminal except Ghostty slowly ([herdr#5512](https://github.com/herdrdev/herdr/issues/5512)). iTerm2 shows it most: a page takes about 3.5 s to paint, and `G` takes up to 2 s. In kitty and WezTerm, the lag is hard to see. Starting herdr with `TERM_PROGRAM=ghostty herdr` fixes the lag, but then herdr also treats the terminal as Ghostty for notifications and focus.

Under herdr with Ghostty, a copy larger than about 220 KB doesn't reach the clipboard over OSC 52. On your own Mac it still copies.

## Mouse pointer

The pointer turns into a hand over links and buttons in Ghostty, kitty and iTerm2. WezTerm and herdr don't change it.

## Claude Code plugin

In the Claude Code desktop app and the VS Code extension, the plugin's pane can't click links or select text.

## Read-only

mddog is a viewer. Clicking a task list checkbox doesn't change it. Press `e` to edit the file.
