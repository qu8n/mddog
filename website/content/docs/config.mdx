## Config file

To change a default setting, create a config file `~/.config/mddog/config.toml`. (If `XDG_CONFIG_HOME` is set, use `$XDG_CONFIG_HOME/mddog/config.toml` instead.)

This is a config with every key at its default value:

```toml title="~/.config/mddog/config.toml"
theme = "light:github-light,dark:github-dark"
copy_on_select = false
```

In your own config, you only need to set the keys you want to change.

After making a change, restart mddog to see it since mddog reads the config only at startup.

## `theme`

This value sets the page's colors and fonts.

The value can be one theme, which mddog always uses:

```toml
theme = "github-dark"
```

Or it can be a `light` and `dark` pair:

```toml
theme = "light:obsidian-light,dark:obsidian-dark"
```

With a pair, mddog follows the [macOS appearance](https://support.apple.com/en-bh/guide/mac-help/mchl52e1c2d2/mac): light mode automatically uses the `light` theme, and dark mode the `dark` theme.

A theme is a built-in name or a path to a custom theme file.

- Built-in themes include `github-light`, `github-dark`, `obsidian-light`, and `obsidian-dark`
- A theme file is any value that ends in `.css` or has a `/` in it. A relative path starts from the config folder, and `~/` is your home folder

See [Themes](/docs/themes) for more about themes and how to make your own.

## `copy_on_select`

In the preview mode, you can select text by dragging it with the mouse or double-clicking to select a word.

By default, `copy_on_select` is set to `false`: selecting text only highlights it, and `Cmd-c` copies it.

When set to `true`, mddog automatically copies to clipboard the text you select. `Cmd-c` might not always work in certain terminals (such as iTerm2), so this option is a good workaround.

## Font smoothing

mddog automatically applies font smoothing if your macOS system does. This makes text look better on some displays, but it can make it blurry on others.

To turn font smoothing off for macOS and mddog, run this and then restart mddog:

```sh
defaults write -g AppleFontSmoothing -int 0
```

To turn it back on:

```sh
defaults delete -g AppleFontSmoothing
```
