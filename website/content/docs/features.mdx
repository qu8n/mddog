## What the page shows

mddog draws GitHub Flavored Markdown as GitHub does:

- Headings, lists, task lists, tables, quotes, rules and footnotes
- Code blocks with syntax colors, and `diff` blocks with added and removed lines
- Alerts: `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]` and `[!CAUTION]`
- Math in `$...$`, `$$...$$` and `math` code blocks
- Mermaid diagrams in `mermaid` code blocks
- Local and remote images, including SVG
- Safe raw HTML, such as `<details>`, `<mark>`, `<kbd>` and `<div align="center">`. Scripts, styles and event handlers are dropped
- YAML front matter, as a table of its top-level keys

mddog downloads remote images on its own, over HTTP and HTTPS, and keeps them in `~/Library/Caches/mddog` for up to an hour. They load after the page first shows. When an image arrives, the page lays out again and keeps what you were reading in view. If an image fails to load, its alt text stays.

## Search

Press `/` or `Ctrl-f`, type, and press `Enter`. mddog highlights every match and jumps to the first one at or below the top of the screen. Press `n` and `N` to go to the next and previous match. The search wraps around at the ends and says so in the status row.

- A query in all lowercase ignores case. A query with an uppercase letter matches case exactly.
- The query is plain text, not a regular expression.
- A match can cross bold, italic and other formatting, and line breaks inside a paragraph.
- `Esc` clears the search. Press `n` after that to run the last search again.

## Contents

Press `t` to show the contents panel on the left. It lists the document's headings and highlights the section you're reading. Click an entry to jump to it. The panel needs a terminal at least 40 columns wide.

You don't need the panel open to jump between sections:

- `1` to `9` jump to the Nth top-level section. Press the same digit again to step through its subsections, or press `0` first to step backward.
- `J` and `K` (or `]]` and `[[`) go to the next and previous section.

## File list

Run `mdd` with no file, or press `Ctrl-p` in the preview, to see the Markdown files near you. The list shows the `.md` and `.markdown` files in the git repo, or in the current folder when there's no repo, up to 10,000 files. It skips hidden files and the files your `.gitignore` and `.ignore` files leave out.

Each row shows the file's path, its first heading, and how old it is. The newest files come first. Type to filter with a fuzzy match on the path and the heading, then press `Enter` to open a file.

After you open a file from the list, `Backspace` goes back to the file before it, at the same place.

## Links

Click a link to follow it:

- A web link opens in your browser, and a `mailto:` link in your mail app.
- A `#heading` link scrolls to that heading.
- A relative link to a `.md` or `.markdown` file opens it in mddog, at the heading if the link names one.
- A link to a folder opens its `README.md` or `README.markdown`, as GitHub does.

Press `Backspace` or `Ctrl-o` to go back. This also undoes jumps from the contents, search and section keys, up to 50 steps.

For safety, a link opens only Markdown files, and only inside the current repo. With no repo, the limit is your home folder. A link to any other local file shows a notice and opens nothing. Links with other schemes, such as `javascript:`, do nothing.

## Select and copy

- Drag to select text, or double-click a word. Press `Cmd-c` to copy the selection. To copy as soon as you let go of the mouse, set [`copy_on_select`](/docs/config#copy_on_select).
- Each code block and Mermaid diagram has a copy button at its top right.
- Press `c` to copy the whole file's Markdown source.

Copies go to the macOS clipboard, and also to your terminal over OSC 52, so they work over SSH too. See [Limitations](/docs/limitations) for which terminals pass `Cmd-c` to mddog.

## Wide code blocks and tables

A code block or table wider than the page scrolls sideways, as in a browser. It shows a scroll bar along its bottom edge.

- `Shift` + mouse wheel, or a sideways wheel, scrolls the block under the pointer.
- `h` and `l` (or `Left` and `Right`) scroll every wide block on screen.
- Drag the scroll bar.
- Press `w` to wrap long lines in code blocks instead.

## Diagrams

A Mermaid diagram wider than the page shrinks to fit and gets a zoom bar. Zoom in, then drag inside the diagram to pan. Click the expand button to see the diagram alone, scaled to fill the screen. Press any key to go back.

## Zoom

Change your terminal's font size with `Cmd-+` and `Cmd--`, and the page zooms with it. The text wraps again at the new size and keeps the same place in view. This needs a terminal that reports its window size in pixels, which the [supported terminals](/docs/terminals) do.

## Live reload

When you preview a file, mddog watches it. Save a change from any editor and the page reloads within a moment, at the same place, with the notice `Reloaded`. If the file is deleted, mddog keeps showing the last version and says so in the status row.

A preview of standard input doesn't reload.

## Edit

Press `e` or `v` to open the file in your editor. mddog runs `$EDITOR` in the same terminal, or `vi` when `$EDITOR` isn't set. `$EDITOR` can include arguments, such as `code --wait`. When you quit the editor, mddog shows the page again with your changes.

## Pause

Press `Ctrl-z` to pause mddog and go back to the shell. Run `fg` to bring it back.
