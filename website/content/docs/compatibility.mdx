## Terminal emulators

| Terminal | Supported | Notes |
|---|---|---|
| Ghostty | <Yes /> | None |
| iTerm2 | <Yes /> | `Cmd-c`/`Super-c` doesn't reach mddog because iTerm2 uses it for its own copy. As a workaround, set [`copy_on_select = true`](/docs/config#copy_on_select) to automatically copy a selection |
| kitty | <Yes /> | None |
| Konsole | <Yes /> | `Super-c` copies the whole file instead of the selection, because Konsole sends it to mddog as `c`. As a workaround, set [`copy_on_select = true`](/docs/config#copy_on_select). Konsole before 24.12 ignores OSC 52, so copying needs `xclip`, `xsel` or `wl-copy` installed |
| WezTerm | <Yes /> | `Cmd-c`/`Super-c` doesn't reach mddog because WezTerm uses it for its own copy. To fix it, set `enable_kitty_keyboard = true` and remove WezTerm's `Cmd-c`/`Super+c` binding |
| Rex | <Yes /> | <ul><li>Claude Code doesn't show images in Rex, so the [`/mddog` pane](/docs/claude-code) only says "this terminal can't show images". As a workaround, start Claude Code with `CLAUDE_CODE_FORCE_TERMINAL_IMAGES=1 claude`</li><li>Restoring a Rex session reopens mddog on the file or file list it had open (OSC 7577). Rex resumes only commands its resume rules allow, and its built-in rules cover only claude, codex and opencode, so add a [resume rule](https://www.superlogical.com/rex/docs/customize/resume-rules#adding-a-rule) for mdd to Rex's `init.lua`: `rex.set("resume.trust.mdd", { command = { "mdd", rex.match.under("~") } })`. It works only when mdd is started by name, and only for files under the home folder</li></ul> |
| Terminal.app, Alacritty | <No /> | Can't show images |
| GNOME Terminal, Console, Ptyxis, foot, xterm | <No /> | Can't show kitty graphics |
| Warp | <No /> | Can't crop images, but mddog needs to crop images to scroll ([Warp#16424](https://github.com/warpdotdev/Warp/issues/16424)) |

## Multiplexers

| Multiplexer | Supported | Notes |
|---|---|---|
| herdr | <Yes /> | <ul><li>Feels slow in every terminal except Ghostty ([herdr#5512](https://github.com/herdrdev/herdr/issues/5512)). Starting herdr with `TERM_PROGRAM=ghostty herdr` fixes the lag, but then herdr also treats the terminal as Ghostty for notifications and focus</li><li>The mouse pointer doesn't turn into a hand over links and buttons because herdr ignores mddog's request to change the pointer</li><li>With Ghostty over SSH, a copy larger than about 220 KB doesn't reach the clipboard</li><li>In supported terminals, mddog runs anyway instead of showing an error because herdr overrides `TERM_PROGRAM`, preventing mddog from detecting the terminal</li></ul> |
| screen | <No /> | Can't show images |
| tmux | <No /> | Can't show kitty graphics yet ([tmux#5445](https://github.com/tmux/tmux/pull/5445)) |
| zellij | <No /> | Garbles scrolled images ([zellij#5573](https://github.com/zellij-org/zellij/issues/5573)) |

## Linux

- mddog draws text with the system fonts, and a server/container may have none. Install a font package such as `fonts-dejavu-core`, and Noto Color Emoji and Noto CJK for emoji and CJK text
- Web images need the `ca-certificates` package. Without it, mddog shows each image's alt text
- If the page looks too big or too small, set `MDDOG_SCALE`, for example `MDDOG_SCALE=1.5 mdd README.md`
- mddog copies with `wl-copy` (package `wl-clipboard`), `xclip` or `xsel`, and also through the terminal with OSC 52. Without any of them, copying works only in terminals that support OSC 52
- Links open with `xdg-open` (package `xdg-utils`). Without it, as on a server, mddog copies the link instead, so you can paste it into a browser on your own machine. To send links somewhere else, set [`open_command`](/docs/config#open_command)
