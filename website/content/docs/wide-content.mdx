## Code blocks and tables

A code block or table wider than the page can be scrolled horizontally, like in the browser.

<WideTablePreview className="my-6" />

You have many options to scroll:

- `Shift` + mouse wheel, or a sideways wheel, scrolls the block under the pointer
- `h` and `l` (or `Left` and `Right`) scroll every wide block on screen
- Drag the scroll bar
- Press `w` to wrap long lines in code blocks instead

## Diagrams

A Mermaid diagram wider than the page shrinks to fit and gets a zoom bar. Zoom in, then drag inside the diagram to pan.

You can also click the expand button to see the diagram alone, scaled to fill the screen. Press any key to go back.

## Zoom

Change your terminal's font size with `Cmd-+` and `Cmd--`, and the page zooms with it. The text wraps again at the new size and keeps the same place in view.

This needs a terminal that reports its window size in pixels, which the [supported terminals](/docs/terminals) do.
