## Install or update

Run the install script. Run it again to update to the latest release.

```sh
curl -fsSL https://raw.githubusercontent.com/qu8n/mddog/main/install.sh | sh
```

The script:

1. Checks that you're on macOS.
2. Downloads the latest release for your Mac (Apple silicon or Intel).
3. Checks the download against its SHA-256 checksum.
4. Puts `mdd` in `~/.local/bin`, replacing any older copy.
5. Tells you how to add that folder to your `PATH` if it isn't there yet.

mddog doesn't leave anything running in the background.

To install somewhere else, set `MDDOG_INSTALL_DIR` to a folder you can write to:

```sh
curl -fsSL https://raw.githubusercontent.com/qu8n/mddog/main/install.sh | MDDOG_INSTALL_DIR=~/bin sh
```

Check which version you have with `mdd --version`.

If you use the [Claude Code plugin](/docs/claude-code), update the plugin each time you update `mdd`.

## Build from source

Install [Rust](https://rust-lang.org/tools/install/) first, then run:

```sh
git clone https://github.com/qu8n/mddog.git
cd mddog
cargo install --path .
```

This puts `mdd` in `~/.cargo/bin`.

## Uninstall

Delete the `mdd` binary, the image cache, and your config folder if you made one:

```sh
rm ~/.local/bin/mdd
rm -rf ~/Library/Caches/mddog
rm -r ~/.config/mddog
```
