---
title: Search
description: Find text on the page.
---

Press `/` or `Ctrl-f`, type a query, and press `Enter` to search.

While in search mode, press `n` and `N` to go to the next and previous match. Press `Esc` to clear the search, and press `n` after that to run the last search again.

A query in all lowercase ignores case, while a query with an uppercase letter matches case exactly.
