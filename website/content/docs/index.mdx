## Requirements

- macOS or Linux
- A terminal that supports the [kitty graphics protocol](https://sw.kovidgoyal.net/kitty/graphics-protocol/): Ghostty, iTerm2, kitty, Konsole, WezTerm, or Rex

See [Compatibility](/docs/compatibility) for what works, what doesn't, and available workarounds.

## Install

```sh
curl -fsSL https://mddog.pages.dev/install.sh | sh
```

Run the same command again to update. If you use the [Claude Code plugin](/docs/claude-code), update the plugin too.

The script downloads the latest release and puts the `mdd` binary in `~/.local/bin`. To install somewhere else, set `MDDOG_INSTALL_DIR` to a folder you can write to.

On macOS, you can use Homebrew instead:

```sh
brew install qu8n/tap/mddog
```

To update, run `brew upgrade mddog`.

<details>
  <summary>Install with Nix</summary>

  ```sh
  nix profile add github:qu8n/mddog   # install
  nix run github:qu8n/mddog           # or try it without installing
  ```

  To update, run `nix profile upgrade mddog`.

  To add it to your system flake instead, add the input:

  ```nix
  inputs.mddog = {
    url = "github:qu8n/mddog";
    # Optional: reuse your own nixpkgs input (not used on Intel Macs)
    # inputs.nixpkgs.follows = "nixpkgs";
  };
  ```

  Then add `inputs.mddog.packages.${pkgs.stdenv.hostPlatform.system}.default` to your packages list.

</details>

<details>
  <summary>Build from source</summary>

  Install [Rust](https://rust-lang.org/tools/install/) first, then run:

  ```sh
  git clone https://github.com/qu8n/mddog.git
  cd mddog
  cargo install --path .
  ```

  This puts `mdd` in `~/.cargo/bin`.

</details>

<details>
  <summary>Uninstall</summary>

  Remove the `mdd` binary, the image cache, and your config folder if you made one:

  ```sh
  rm ~/.local/bin/mdd    # or, if you used Homebrew: brew uninstall mddog
                         # or, if you used Nix: nix profile remove mddog
  rm -rf ~/Library/Caches/mddog   # on Linux: rm -rf ~/.cache/mddog
  rm -r ~/.config/mddog
  ```

</details>

## Basic usage

```sh
mdd             # list Markdown files in the current directory to pick from
mdd README.md   # view a file
```
