mddog previews Markdown in your terminal the way GitHub or Obsidian renders it. It works by building the page with macOS's own text and graphics engines, then sending the result to the terminal as images.

## Why mddog?

Other terminal viewers render Markdown with only characters. Code editors render the real page but live outside the terminal. mddog renders the real page in your terminal, using a single binary without browser nor Electron.

## Requirements

- macOS
- A terminal that supports the [kitty graphics protocol](https://sw.kovidgoyal.net/kitty/graphics-protocol/): Ghostty, iTerm2, kitty, WezTerm, or Rex

See [Compatibility](/docs/compatibility) for more info on the supported terminals.

## Install

```sh
brew install qu8n/tap/mddog
```

To update, run `brew upgrade mddog`. If you use the [Claude Code plugin](/docs/claude-code), update the plugin too.

<details>
  <summary>Install without Homebrew</summary>

  ```sh
  curl -fsSL https://raw.githubusercontent.com/qu8n/mddog/main/install.sh | sh
  ```

  The script downloads the latest release and puts the `mdd` binary in `~/.local/bin`. To install somewhere else, set `MDDOG_INSTALL_DIR` to a folder you can write to. To update, run the script again.

</details>

<details>
  <summary>Build from source</summary>

  Install [Rust](https://rust-lang.org/tools/install/) first, then run:

  ```sh
  git clone https://github.com/qu8n/mddog.git
  cd mddog
  cargo install --path .
  ```

  This puts `mdd` in `~/.cargo/bin`.

</details>

<details>
  <summary>Uninstall</summary>

  Remove the `mdd` binary, the image cache, and your config folder if you made one:

  ```sh
  brew uninstall mddog   # or, if you used the script: rm ~/.local/bin/mdd
  rm -rf ~/Library/Caches/mddog
  rm -r ~/.config/mddog
  ```

</details>

## Basic usage

```sh
mdd             # list Markdown files in the current directory to pick from
mdd README.md   # preview a file
```
