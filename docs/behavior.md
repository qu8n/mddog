# Behavior spec

The key and event contract for the viewer. It started from leaf's Document mode. `python3 reference/keymap-check.py` checks that every test named in the last column ran and passed.

Source: leaf `07653b83749b74aafbad926374b0e86967201221`, Document mode, read in full. The `leaf source` column names files in leaf at that commit (`keyboard.rs`, `navigation.rs`, and so on), not files in mddog. Units: one row is one terminal cell row. `H` is the viewport height: terminal rows minus one status row. leaf appends 5 blank rows to every document, so `total` is the document's rows plus 5, and `max = max(0, total - H)`. Every row below except row 46 has a test named in the last column (in `src/viewer/app.rs` unless noted).
